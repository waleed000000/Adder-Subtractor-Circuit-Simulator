# Adder and Subtractor Circuit Simulator

## Project Overview
This project is developed for Digital Logic Design. It simulates the working of Adder and Subtractor circuits.

## Objectives
- Understand binary addition.
- Understand binary subtraction.
- Implement digital logic circuits.
- Demonstrate the working of Adder and Subtractor circuits.

## Features
- Half Adder
- Full Adder
- Half Subtractor
- Full Subtractor
- Circuit simulation and output verification
